# 间隔重复

## 核心原理

记忆痕迹会随着时间消退，而且消退速度是先快后慢。间隔重复的原理就是在记忆即将消退的时间点附近安排复习，每次成功的提取都会让记忆痕迹维持更久，所需复习间隔也越来越长。本质是用提取练习强化长时记忆，而不是重新阅读。

## 工具对比

Anki 使用 SM-2 算法的变体，根据每次回忆的难易程度动态调整下次间隔，上手简单、生态成熟。SuperMemo 的间隔算法迭代到 SM-18，引入了记忆稳定性与可提取性两个维度，理论上更精细，但操作复杂。日常学习 Anki 已经足够，SuperMemo 更适合愿意深入研究算法本身的人。

## 安排节奏

实操上先以 1 天、3 天、7 天、16 天的间隔开始，回忆失败就重置到上一级间隔。每天新卡片不要超过 20 张，否则复习量会指数累积。卡片的写法遵循"一卡一知识点"，正面只问一个问题，避免复合问题导致判断困难。
