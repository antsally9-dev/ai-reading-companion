# 记忆宫殿法

## 原理

记忆宫殿利用空间记忆的优势，把要记的信息挂在熟悉空间的各个位置上，回忆时按路线走一遍就能依次提取。竞技记忆选手记扑克牌和数字都用这个方法。

## 步骤

先选一个熟悉的空间，比如自己的家；然后在路线上确定固定的位置桩；把要记的信息转换成夸张生动的图像，与位置桩产生互动；最后按顺序在脑中走路线提取。

## 适用性

适合记忆无序清单、演讲要点、扑克牌等任意信息；不适合需要深层理解的材料，理解型材料还是要靠间隔重复和主动回忆。
